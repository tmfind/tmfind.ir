پروژه اندروید TM Find
=====================
این پروژه، فایل HTML موجود در ZIP ارسالی را داخل یک اپ اندروید (WebView) نمایش می‌دهد.

مهم:
- این فایل APK آماده نیست؛ سورس پروژه اندروید است و باید با Android Studio ساخته شود.
- قالب ارسالی فقط index.html و README دارد و طبق README خودش فرانت‌اند نمایشی است؛ بک‌اند واقعی ندارد.
- ورود پیامکی، پرداخت، آگهی‌ها و داده‌های مدیریتی نمایشی هستند و برای کار واقعی باید بک‌اند و سرویس‌های مربوط متصل شوند.

ساخت APK:
1) Android Studio را نصب کنید: https://developer.android.com/studio
2) Android Studio > Open و پوشه TMFindAndroid را انتخاب کنید.
3) اجازه دهید Gradle Sync تمام شود و SDK پیشنهادی را نصب کنید.
4) از منوی Build > Build APK(s) استفاده کنید.
5) APK معمولاً در app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

این پروژه برای ساخت نسخه آزمایشی (debug) است. برای انتشار عمومی باید امضای release، حریم خصوصی، امنیت و بک‌اند بررسی شوند.
